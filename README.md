# Макроэкономика: технологический разрыв США и Китая

Магистерский проект: панель OECD + Китай, гипотезы H1–H7 (R&D, TFP, Солоу, полупроводники, TOP500, ИИ).

## Результаты

| Путь | Что внутри |
|------|------------|
| `reports/` | Отчёт, упрощённая версия, презентация |
| `results/deep/` | Таблицы и графики |
| `data/` | Сырые данные и панель |

## Код

| Путь | Назначение |
|------|------------|
| `src/macrodeep/` | Общая библиотека |
| `notebooks/deep/` | Анализ `D00`–`D11` |
| `scripts/deep/` | Загрузка данных и сборка панели |
| `tests/` | Smoke-тесты |

## Запуск

```bash
pip install -r requirements-deep.txt
pip install -e .
python notebooks/run_all.py
```
