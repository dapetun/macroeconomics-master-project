# 1. Executive summary

Deep-research уже **реализован** (вопреки статусу «ничего не реализовано» в `METHODOLOGY_OPTIONS.md`): панель OECD+Китай 39×2000–2023, гипотезы H1–H7, таблицы и графики на месте. Часть идей OPTIONS действительно усиливает работу: `rtfpna` вместо `ctfp` как зависимой, разложение Солоу, импорт/баланс по чипам, отказ от DiD/IV/ML. Другая часть либо **сломана в коде**, либо **перегружает** учебный проект, либо **не закрывает** центральный сюжет «два пути → экономический эффект».

**Что хорошо**

- Честный отказ от причинных методов (DiD/IV/SC) при отсутствии дизайна.
- Правильная диагностика `ctfp` (уровень относительно США, не рост внутри страны).
- Расширение панели с 8 до 39 стран снимает главную слабость старого M1 (G≈7).
- H5 (торговля микросхемами) на данных **работает**: Китай — чистый импортёр все 14 лет 2010–2023.
- Язык выводов в `DEEP_RESULTS` / `D11` в целом ассоциативный, без «доказано».

**Главные проблемы**

1. **Исследовательский вопрос шире, чем позволяют данные и результаты.** Вопрос просит подтвердить «образ двух путей» по всей цепочке; количественно закрыты отдельные звенья, а H1/H3/H4 частично **не согласуются** с заявленным образом.
2. **TOP500: мощность (Rmax) для ключевых лет = 0** из‑за бага нормализации колонок (`RMax` / `Rmax` / `Rmax [TFlop/s]`). Доля по числу систем есть; сравнение «мощность vs число» для 2010, 2019, 2022, 2024, 2025 **не проверено**.
3. **H2 выглядит сильнее, чем есть:** overall R² ≈ 0,98 за счёт FE; within-R² ≈ 0,20. Эластичность ≈ 1 осмысленна, но текст/защита легко переоценят «почти идеальную» модель.
4. **H3 — центральная идея «два пути через R&D×gap» — незначима** (β₃ ≈ −0,45, p ≈ 0,54). Её нельзя оставлять «главным эконометрическим сюжетом» отчёта.
5. **`rd_ppp` сконструирован** как интенсивность × ВВП PPP; абсолютный OECD GERD почти пуст. Для уровней и эластичностей это proxy с риском почти механической связи с размером экономики.
6. **Hausman не поддерживает FE** (статистика ≈ 0,11, p ≈ 0,74), хотя теория за FE. В тексте нельзя писать «тест Хаусмана выбрал FE».
7. **Git-схема «CURRENT» не существует**; `main`/`retro` = старый снимок; актуальная база deep — `report-20pp`. Путаница имён, не потеря кода.

**Сомнительные / лишние элементы**

- LPM по открытости моделей (H7) как «доказательство модели США/Китая» — хрупко (пропадает при drop top-3 CN orgs).
- Набор robustness в D03/D04 шире, чем нужно для защиты.
- Вариант C из OPTIONS (кластеры / PCA-профили) — rightly не делать.
- Обещание OPTIONS «≈2–3 выходных на B» при фактическом B + куски C — заниженная оценка трудозатрат/сложности защиты.

# 3. Research question audit

## 3.1. Текущий вопрос (`DEEP_RQ_AND_HYPOTHESES.md`)

> Согласуются ли данные 2000–2023 с образом двух разных путей … и в каких звеньях цепочки «наука → … → экономический эффект» различия проявляются, а в каких нет?

**Оценка**

| Критерий | Оценка |
|----------|--------|
| Конкретность | Средняя: «образ двух путей» — нарратив, не один измеримый контраст |
| Измеримость | Частичная: отдельные H1–H7 измеримы; цепочка целиком — нет |
| Связь с данными | Хорошая для H2/H4/H5; слабая для «внедрение» и tech→TFP |
| Масштаб проекта | Завышен для учебного срока, если вопрос читать буквально |

## 3.2. Логика гипотез

| H | Заявлено | Что реально измеряет | Проблема перехода |
|---|----------|----------------------|-------------------|
| H1 | Профиль «масштаб vs интенсивность» vs норма дохода | Остатки от pooled OLS по OECD+CHN | Норма смещена к богатым странам; ожидание «CHN intensity слабее масштаба» **не** выполняется чисто (rd_gdp CHN тоже +91%) |

# 6. Econometric audit

## 6.1. Pooled OLS (норма H1)

Уместен для descriptive norm. Не причинность. Year FE — да. Country FE в норме **не** нужны (иначе остаток «выбивания из собственной средней», не из кросс-страновой нормы) — сделано правильно.

## 6.2. Multiple regression / TWFE (H2, H3)

- FE убирают постоянные различия стран и общие шоки лет.
- **Не** убирают: обратную причинность, time-varying omitted, measurement error.
- G=39: лучше, чем 7, но всё ещё на нижней границе для комфортной cluster-asymptotics.
- Cluster SE по стране — нужны; сказать, что при G≈40 это приближение.

## 6.3. FE vs RE

Теория (R&D связан с ненаблюдаемыми особенностями страны) → FE.  
Тест Хаусмана на текущей спецификации **не** выбирает FE.  
**Нельзя** на защите: «Hausman доказал FE». Можно: «выбрали FE по содержательным причинам; Hausman не отверг RE».

## 6.4. Лаги

Лаг 1 для R&D→патенты / TFP экономически правдоподобен как «минимум на реализацию», но **не идентифицирует** причинность. Показ lag 0/1/2 как robustness — ок; не подбирать лаг под p-value в тексте.

## 6.5. Interactions

`rd × gap` и `rd × CHN` — содержательны, но требуют аккуратной интерпретации (центрирование, маржинальный эффект). При незначимом β₃ взаимодействие не «провалилось как метод», а **не поддержало** гипотезу.

## 6.6. FE ≠ causal

Серьёзная ошибка была бы подразумевать, что TWFE = эффект R&D. В deep-документах в целом этого нет; риск — в устных формулировках и в переоценке H2 R².

## 6.7. Robustness — что оставить

**Must:** без CHN; альтернативная Y (articles / pat_tot); окно до 2019; within-R² рядом с overall.  
**Should:** лаги 0/1/2; dln_lp вместо dln_tfp для H3.  
**Could:** rd_stock; 5-year averages.  
**Remove:** длинные каскады спецификаций, которые не меняют вывод.

# 7. Causal inference audit

| Метод | Вердикт |
|-------|---------|
| DiD (CHIPS / export controls) | **Метод не следует использовать.** 1–2 года после шока; нет чистой control group; лаг строительства fab 3–5 лет. |
| Event study | **Не следует использовать.** Те же причины. |
| Synthetic control (MIC2025 и т.п.) | **Не следует использовать.** Китай — крайний случай; параллельно много политик. |
| IV для странового R&D | **Не следует использовать.** Нет защищаемого инструмента. |

OPTIONS здесь правы. Deep их не внедрял — хорошо. Вертикали 2022 на графиках торговли — только даты-ориентиры, не causal.

# 9. ML audit

Какой RQ решает ML? **Никакой** из сформулированных.  
Задача — интерпретируемые ассоциации и описания, не out-of-sample prediction.  
При N≈800 и сильной корреляции входов feature importance неустойчива и плохо защищается.  
**Вывод:** ML не добавлять. Не называть PCA/кластеры «ML-вкладом» ради галочки.

# 11. Macro-economic linkage audit

Целевая цепочка:

```text
Technology → Adoption / production → Productivity → Economic outcomes
```

| Звено | Статус в deep |
|-------|----------------|
| R&D → patents/articles | Оценено ассоциативно (H2) |
| R&D → ΔTFP (heterogeneous) | Оценено; **не поддержано** (H3) |
| Inputs → growth (Solow) | Учёт (H4) — лучший макро-мост |
| Tech (AI/HPC/chips) → TFP | **Не идентифицировано** |
| Adoption / внедрение | **Отсутствует** |
| Long-run advantage | **Не выводится** (D11 level 8) |

Чего не хватает для полной цепочки: внедрение, отраслевая производительность, fab.  
Добавлять ли в рамках проекта? **Нет** — данных нет бесплатно/сопоставимо. Лучше сузить вопрос и усилить честную карту доказательств (уже есть `D11_claim_ladder.csv`).
