## Главный исследовательский вопрос

Согласуются ли данные 2000–2023 годов с образом двух разных путей технологического развития — американского (работа у технологического фронтира, интенсивность исследований, контроль над передовыми звеньями и закрытость передовых моделей) и китайского (масштаб, догоняющее освоение технологий, производственная база, открытость моделей) — и в каких звеньях цепочки «наука → инновации → производство → вычисления → экономический эффект» эти различия проявляются, а в каких нет?

## H1 — отклонение от нормы для уровня дохода (ПВ1)

| Поле | Содержание |
|------|------------|
| Тип | Описательное |
| Операционализация | Остатки `e_it` из `ln(k)_it = a + b1·ln_gdppc + b2·ln_pop + d_t + e` для k ∈ {rd_gdp, researchers_pm, articles/pop, pat_res/pop, mva_share, hitech_share} |
| Предсказание | У Китая «масштабные» показатели (патенты, статьи, промышленность, hi-tech) выше нормы сильнее, чем интенсивность R&D; у США выше нормы прежде всего интенсивность R&D |
| Противоречит | У Китая интенсивность R&D выше нормы сильнее, чем масштабные показатели; у США наоборот |
| Конкурирующее объяснение | Норма OECD смещена вверх по доходу → Китай на нижнем краю |
| Проверка конкурента | Оценка нормы без Китая; квадрат ln_gdppc |
| Неопределённо | CI остатков пересекает 0 на ключевых годах |
| Основная спецификация | pooled OLS + year FE, без country FE |
| Robustness | без CHN в оценке нормы; + (ln_gdppc)²; окно 2010–2023 |

## H2 — R&D → патенты (ПВ2)

| Поле | Содержание |
|------|------------|
| Тип | Ассоциативное |
| Операционализация | `ln_pat_res_it = a_i + d_t + b·ln_rd_ppp_{i,t−1} + e`; расширение + ln_researchers; + взаимодействие × is_chn |
| Предсказание | b > 0; взаимодействие с Китаем ≥ 0 (больше патентов на единицу R&D) |
| Противоречит | b ≤ 0 при устойчивых проверках |
| Конкурирующее объяснение | Субсидии на подачу заявок в Китае |
| Проверка конкурента | без CHN; зависимая ln_articles; ln_pat_tot |
| Неопределённо | CI для b включает 0 при cluster SE |
| Основная | TWFE, лаг 1 |
| Robustness | лаги 0/1/2; rd_stock; без CHN; 2000–2019; пятилетние средние |

## H3 — R&D × отставание от фронтира → рост TFP (ПВ3)

| Поле | Содержание |
|------|------------|
| Тип | Ассоциативное |
| Операционализация | `dln_tfp = a_i + d_t + β1·rd_c + β2·gap_c + β3·rd_c·gap_c + e`; gap = −ln(ctfp); rd и gap центрированы |
| Предсказание | β3 > 0 (R&D сильнее связан с ростом TFP у стран дальше от фронтира) |
| Противоречит | β3 ≤ 0 устойчиво |
| Конкурирующее объяснение | Ошибки измерения TFP → механический догоняющий рост |
| Проверка конкурента | зависимая dln_lp; пятилетние средние; без самых отстающих |
| Неопределённо | CI для β3 включает 0 |
| Основная | TWFE, лаг 1, cluster SE |
| Robustness | 5-летние; dln_lp; rd_stock; лаги 1–3; без 2020–21; без CHN; без взаимодействия |

## H4 — источники роста (ПВ4)

| Поле | Содержание |
|------|------------|
| Тип | Описательное (учёт) |
| Операционализация | Разложение Солоу: g_Y = ᾱ g_K + (1−ᾱ)(g_L+g_h) + g_A |
| Предсказание | У Китая доля капитала в росте больше, доля TFP меньше, чем у США |
| Противоречит | У Китая доля TFP ≥ доли США по основным периодам |
| Конкурирующее объяснение | Завышение капитала Китая в PWT |
| Проверка конкурента | сверка g_A с Δln rtfpna; периодные окна |
| Неопределённо | доли близки (±5 п.п.) |
| Основная | периоды 2001–07, 2008–12, 2013–19, 2020–23 |
| Robustness | разложение на занятого; сравнение KOR/JPN/DEU |

## H6 — TOP500 (ПВ6)

| Поле | Содержание |
|------|------------|
| Тип | Описательное |
| Операционализация | Доли систем и Rmax; новые появления; архитектура ускорителей; сегменты |
| Предсказание | Доля Китая выросла, затем упала после ~2019 из‑за меньшего числа новых подач; доля по мощности < доли по числу систем; верх США — GPU NVIDIA/AMD, верх Китая — собственные процессоры |
| Противоречит | Доля Китая растёт после 2019; архитектуры не различаются |

| Проверка конкурента | число новых систем First Appearance |
| Неопределённо | доли стабильны без тренда |
| Основная | ноябрьские списки 2010–2025 |
| Robustness | топ-10 / топ-50; эксафлопсные системы |

## H7 — открытость моделей ИИ (ПВ7)

| Поле | Содержание |
|------|------------|
| Тип | Ассоциативное |
| Операционализация | Epoch notable models; open vs closed; LPM `open ~ is_chn + year FE + domain FE + org_type FE` |
